Notices & Important Guidelines

1. Nature of this Website

This is a **static demonstration** built for educational and presentation purposes only.

No real MHADA lottery is being conducted. No housing units are being allotted.

2. How the Demo Lottery Works

  • Data stored in plain JavaScript file (data.js)
  • Fisher-Yates shuffle → random winner selection
  • Random flat assignment from demo list
  • Result passed via URL parameters (no storage)
  • Printable layout simulated using CSS @media print
